LC LabelCheck

Review a label, step by step.

  1. Upload clear PNG, JPEG or WebP images. Use Rotate if the label is sideways.
  2. Select a label in the queue and enter its application values. Values belong to that individual label.
  3. Choose Verify selected label, or Verify queue to process all labels sequentially.
  4. Compare flagged readings against the image. Confirm the warning formatting yourself using the dropdown.
  5. Export the review as JSON. Images and application values are not stored on a server.

For a batch, upload images first, then import a JSON array using the example file. Each filename must match an uploaded image exactly. Maximum image size is 15 MB. PNG, JPEG and WebP only; PDF and HEIC are not supported.

What this prototype checks

Local neural OCR reads text. Deterministic comparison checks supplied brand, type, ABV, volume, producer and origin values, plus standard warning wording and uppercase heading. Equivalent liter and milliliter volumes match. Case and punctuation differences in application names are tolerated.

Missing values and unclear readings need review. OCR confidence below 75 sends otherwise matching readings to review. The confidence score is an OCR heuristic, not a probability that a label complies.

Typography, physical type size, placement, glare and category-specific labeling rules still require human review. Warning formatting is recorded only after reviewer confirmation. This tool does not issue regulatory approval.

The engine and English language data are served with the app. Initial preparation can exceed five seconds; later reads reuse the engine. Performance depends on the device and image. Current implementation does not guarantee the five-second target. The app does not persist a review after refresh; export before leaving.
